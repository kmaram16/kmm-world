# KMM World

**EN:** An open-world game for Windows and Android (Unity) made by KMM — you can do EVERYTHING: deliver pizza, be a police officer, ride motocross, play as Super Perro, become a YouTuber, survive a zombie night, escape the haunted school (5 nights with Norberto), run your own arcade (tycoon) and survive on the island with Kamyar and Mami against Captain Norberto's pirates. Kid-safe. Spanish UI with an English option. Early version (v0.2).

**ES:** Un juego de mundo abierto para Windows y Android (Unity) hecho por KMM — puedes hacerlo TODO: repartir pizzas, ser policía, motocross, Super Perro, YouTuber, noche zombi, escuela encantada (5 noches con Norberto), tycoon (tu propio arcade) y supervivencia en la isla con Kamyar y Mami contra los piratas del capitán Norberto. Apto para niños. Interfaz en español con opción en inglés. Versión temprana (v0.2).

**Download / Descargar:** [Releases](https://github.com/kmaram16/kmm-world/releases/latest) · https://kmaram16.github.io/arcade/kmmworld/

Controls / Controles: WASD move · Mouse look · Shift run · Space jump · E use/enter · Tab phone · M map · R record · Esc pause. Xbox controller supported.

If Windows SmartScreen appears: More info → Run anyway / Más información → Ejecutar de todas formas.
